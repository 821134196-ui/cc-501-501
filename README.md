# 图文店 · 工程图纸打印管理系统

客户提交工程图纸后选择纸张规格、黑白/彩色、单双面、装订与份数；门店预检图幅与页数后出校样，**客户确认的版本才能进入打印队列**。零依赖（仅 Node ≥ 22 内置模块）：`node:sqlite` 存订单与计费，本地文件存图纸样本，打印机为模拟适配器。

## 一条命令启动（含比例错误样例）

```bash
npm start        # 生成演示数据（含 samples/厂房结构图-A1-比例错误.json）并启动 http://localhost:3000
npm run seed     # 只生成数据不启动
npm test         # 校样锁定 / 计费调整 / 设备竞争 / 重复取件
```

删除 `data/` 可重置演示数据。

## 业务规则

| 场景 | 处理 |
|---|---|
| 补传文件 | 生成新版本，**不覆盖已确认校样**；旧校样保持锁定，新校样确认后旧版转为「被替代」留档 |
| 急单插队 | 任务排到设备队首，整队预计完成时间重算 |
| 字体缺失 / 图层未打印 / 机器卡纸 | 店方承担，免费重印（费用记录为 0，可追溯） |
| 尺寸比例不符 | 客户已确认校样，半价重印（收 50%） |
| 客户临时减量 | 按减量份数退 90%（负值费用），订单份数同步减少 |
| 设备竞争 | 原子认领：两名操作员抢同一任务只有一人能开机 |
| 已交付订单 | 不能再次收费、不能重复取件 |

## 图纸文件格式（JSON 样本）

```json
{
  "name": "厂房结构图",
  "pages": [{
    "width_mm": 841, "height_mm": 594, "declared_scale": "1:100",
    "content_mm": { "w": 73200, "h": 51800 },
    "fonts": ["SimSun", "HZTXT"],
    "layers": [{ "name": "墙体", "print": true }, { "name": "临时标注", "print": false }]
  }]
}
```

预检核算：图幅匹配 ISO A 系列、页数、缺失字体、未打印图层、实际比例（`content_mm / 图幅`，如 `1:87.0` 非标准比例以可读数字标出）。

## 页面

- **订单与上传**：开单、上传图纸（本地样本或 JSON 文件）、预检报告、急单插队
- **校样查看**：带实际图幅标尺（mm）的查看器、点击图面批注、两窗格版本并排可切换、客户确认/驳回
- **操作台**：按设备列出正在打印与待机任务，操作员开机/完成/卡纸/排除
- **费用明细**：费用流水（打印费/重印/退款/调整）、重印登记、临时减量
- **取件核验**：取件码核验，已交付订单拒绝重复取件

界面白色为主、蓝灰用于结构；比例错误以琥珀色可读数字标出。

## 结构

```
src/db.js        SQLite schema（订单/版本/校样/设备/任务/重印/费用/取件）
src/precheck.js  上传预检（图幅/页数/字体/图层/比例）
src/pricing.js   计费规则（基础价 + 各原因重印/减量）
src/service.js   领域服务（校样锁定、队列与急单、原子认领、取件核验）
src/printer.js   打印机模拟适配器
src/server.js    HTTP API + 静态服务
src/seed.js      演示数据（比例错误样例）
public/          前端（校样查看器、操作台）
tests/           node --test 四个场景测试
samples/         本地图纸样本
```
