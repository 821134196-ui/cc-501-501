# 图文快印 · 工程图打印管理系统

面向图文打印店的工程图打印管理:客户提交图纸并选择纸张规格、黑白/彩色、单双面、
装订与份数;门店预检图幅与页数后出具校样,客户确认的版本才能进入打印队列。

纯 Python 标准库实现(无第三方依赖),SQLite 存订单与计费,本地目录存图纸样本,
打印机使用模拟适配器(`app/printer.py`,真实部署时以厂商 SDK 替换同名接口)。

## 启动

```bash
python3 run.py            # 初始化数据库、生成样例(含比例错误样例)、种子设备并启动
python3 run.py --reset    # 清空 data/ 重新初始化
python3 run.py --port 8080
```

打开 http://127.0.0.1:8000 。启动后自带两个演示订单:

- `P…-001` 张伟:**A1 总平面图错选 A3 纸**,预检报比例错误(需缩放至 49.9%),校样待确认
- `P…-002` 李娜:A1 平面图,校样已确认,正在设备队列待机

## 测试

```bash
python3 -m unittest tests.test_rules -v
```

覆盖:校样确认后锁定且补传不覆盖、重印费用规则与减量退款、
两名操作员抢同一任务仅一人开机、重复取件与已交付不再收费、急单插队重算估时。

## 业务规则

| 场景 | 处理 |
|---|---|
| 上传预检 | 解析 SVG 图幅(mm)/页数/字体/图层,与所选纸张比对,比例不符给出可读缩放百分比 |
| 校样 | 确认即锁定,锁定后不可批注;补传生成新版本,已确认校样存档保留不覆盖 |
| 急单 | 插入设备队列头部,队列全部任务预计完成时间顺延重算 |
| 重印-字体缺失 | 店方承担,免费重印(0 元记账) |
| 重印-图层未打印 | 店方承担,免费重印 |
| 重印-机器卡纸 | 店方承担,免费重印 |
| 重印-尺寸比例不符 | 校样已标注且经客户确认,客户承担 50% |
| 客户临时减量 | 未开机前可减,打印/装订/急单加收按差额退款(负费用) |
| 设备竞争 | 同一任务/同一设备原子抢占,仅一名操作员能开机 |
| 取件核验 | 一单只能交付一次;已交付订单费用锁定,不能再次收费 |

## 页面

- **下单**:规格选择 + 样例/文件上传,预检结果展示实际图幅与问题清单
- **校样**:查看器带实际图幅 mm 标尺,两个版本并排可切换,点击图纸添加批注,
  比例错误以可读数字横幅标出;客户确认后订单入队
- **操作台**:按设备列出正在打印与待机任务(含预计完成时间),开机/完成/卡纸/重印
- **订单与费用**:状态流、费用明细(退款为负)、重印记录、临时减量、取件核验

## 结构

```
run.py              一条命令启动(初始化+样例+种子+服务)
app/db.py           SQLite schema 与事务
app/services.py     业务规则(预检/校样/队列/计费/取件)
app/printer.py      模拟打印机适配器
app/samples.py      图纸样例生成(SVG,mm 单位,内嵌页数/字体/图层元数据)
app/server.py       标准库 HTTP 服务(JSON API + 静态页)
static/index.html   单页应用
tests/test_rules.py 业务规则测试
data/               运行时生成:app.db、uploads/、samples/
```
